Welcome to PathFinder!

An interactive shortest path algorithm visualizer

1
Create a graph — Click the canvas to add nodes, then drag between nodes to create edges with weights.
2
Set source & destination — Use the 🟢 Source and 🔴 Dest buttons, then click a node.
3
Pick an algorithm — Choose from Dijkstra, Bellman-Ford, BFS, or A* in the sidebar.
4
Watch it run! — Hit "Run Algorithm" and use the playback controls to step through the visualization.
